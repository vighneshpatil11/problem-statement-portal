# Setup

1. Create a free Supabase project.
2. Open SQL Editor.
3. Replace `YOUR_ADMIN_EMAIL` in `supabase_schema.sql` with the exact admin email.
4. Run the SQL.
5. Go to Authentication → Users → Add user and create that admin email/password.
6. Copy your Supabase Project URL and Publishable/anon key.
7. Put them into `config.js`.
8. Test locally.
9. Upload the files to GitHub.
10. GitHub repository → Settings → Pages → Deploy from branch → main → root.

Files:
- index.html
- style.css
- script.js
- config.js
- supabase_schema.sql
- SETUP.md

There is NO team-size cap. Students are only registering interest.

The statement creator receives an `IDEATOR` tag.

Statement IDs are automatically generated as B01, B02, B03...

Never put a Supabase service_role/secret key in config.js.
